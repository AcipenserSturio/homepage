# Homepage

A quiet but slick browser homepage. Customise links how you like. Your preferences are stored on your device. Supports search with [bangs](https://duckduckgo.com/bangs). Install [New Tab Override](https://addons.mozilla.org/en-GB/firefox/addon/new-tab-override/) to set a start page / new tab page.

## Develop

```sh
npm install
npm run dev
npm run test:browser
```
